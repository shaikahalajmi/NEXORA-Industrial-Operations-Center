# NEXORA — Industrial Operations Center

> An interactive industrial intelligence dashboard for real-time equipment monitoring, operational analytics, and early detection of critical machine conditions.

## 🏭 Overview

NEXORA is a web-based Industrial Operations Center designed to simulate how modern factories can monitor equipment and operational performance from one centralized dashboard.

The platform provides a visual representation of industrial equipment, continuously simulates operational data, detects abnormal machine conditions, and presents key performance indicators through an interactive monitoring interface.

The goal of NEXORA is to transform raw industrial data into clear and actionable operational insights.

---

## 🎯 The Problem

Industrial environments may contain hundreds of machines operating simultaneously.

Monitoring each machine individually can make it difficult to quickly identify:

- Equipment overheating
- Abnormal operating conditions
- Machine downtime
- Low equipment utilization
- Critical equipment requiring immediate attention

NEXORA demonstrates how a centralized monitoring system can help operators identify these conditions faster.

---

## 💡 The Solution

NEXORA combines equipment visualization, live data simulation, automated condition monitoring, and operational analytics into a single dashboard.

The system provides operators with an immediate overview of factory health while allowing individual equipment conditions to be visually identified.

---

## ⚙️ Key Features

### 🗺️ Interactive Factory Map

A visual industrial environment displays multiple machines and their current operating conditions.

Equipment is visually classified based on its condition:

- 🟢 Normal
- 🟡 Warning
- 🔴 Critical

---

### 📡 Live Data Simulation

NEXORA continuously simulates changing operational data to demonstrate real-time industrial monitoring.

Machine conditions and dashboard indicators dynamically update while the system is running.

---

### 🚨 Critical Condition Detection

The dashboard automatically highlights equipment entering abnormal operating conditions.

Critical machines are visually identified and an operational alert is displayed to help operators quickly locate the affected equipment.

---

### 📊 Operational Analytics

The analytics panel provides visual insights including:

- Equipment Metrics
- Equipment Utilization by Station
- OEE (Overall Equipment Effectiveness) trends
- Active / Idle / Downtime distribution

---

### 🏭 Fleet Status Monitoring

The system provides a centralized overview of:

- Total connected devices
- Working equipment
- Equipment requiring attention
- Critical equipment
- Overall operational health score

---

## 🧠 How NEXORA Works

The dashboard simulates operational readings for industrial equipment.

As equipment conditions change, NEXORA evaluates the simulated data and updates:

1. Machine utilization
2. Equipment status
3. Operational health score
4. Warning and critical indicators
5. Factory analytics
6. Critical condition alerts

This creates a simplified simulation of an industrial monitoring environment.
